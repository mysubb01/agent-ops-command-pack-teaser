Data Correction

운영 데이터 수정 전에 AI에게 반드시 시킬 것

돈, 권한, 포인트, 정산 데이터는 바로 수정하면 위험합니다. 먼저 읽기 전용 증거와 단일 진실 테이블을 확인해야 합니다.

실제 데이터를 수정하기 전에 읽기 전용 쿼리로 현재 상태를 증명해줘. 어떤 row를 왜 바꾸는지, 변경 전 값과 변경 후 예상 값을 먼저 보여줘. 수정 후에는 같은 기준으로 재조회하고 감사 로그를 남겨줘.

안전 규칙

  • 수정 대상 row를 먼저 특정
  • 변경 전 값을 표로 기록
  • 단일 진실 테이블 확인
  • 최소 변경만 실행
  • 변경 후 재조회와 감사 로그 확인
