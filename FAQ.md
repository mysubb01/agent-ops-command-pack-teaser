# Agent Ops Command Pack FAQ

## What is this?

Agent Ops Command Pack is a Korean command-template pack for people who use AI coding agents in real operations work.

It focuses on incident triage, production deploy checks, code review, data correction safety, and handoff documentation.

## What is free?

The public repo includes free samples, a static prompt generator, and product information.

## What is in the paid full pack?

The full pack includes:

- 20+ Korean command templates
- Checkpoint JSON template
- Incident report template
- Production smoke checklist
- Marketplace listing copy
- Static landing page source

## Can I use the free samples commercially?

Yes, you can use the public samples in your own workflow.

You may not resell or redistribute the paid full pack as your own product.

## Who is this for?

This is for solo developers, small teams using AI coding agents, operators who need clearer handoffs, and developers who want evidence-based AI prompts instead of vague instructions.
