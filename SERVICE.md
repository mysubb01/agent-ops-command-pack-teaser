# Paid Mini-Sprints

Small paid help for teams using AI coding agents in real operations work.

## Best Fit

- Production bug triage from sanitized logs or public repo context
- AI-generated TypeScript, Next.js, Python, or SQL code cleanup
- Code review focused on bugs, regressions, missing tests, and unsafe assumptions
- Deploy smoke checklists and release handoff notes
- Internal workflow automation around GitHub, docs, prompts, or APIs

## Starter Offers

| Offer | Output | Suggested budget |
|---|---|---:|
| Bug triage note | Cause hypothesis, evidence path, next fix step | 30-75 USD equivalent |
| PR risk review | Findings ordered by severity with file/line references | 30-150 USD equivalent |
| Deploy smoke pack | Checklist plus commands/endpoints to verify | 50-150 USD equivalent |
| Small automation spec | Scoped plan and implementation-ready acceptance criteria | 75-200 USD equivalent |
| AI-code cleanup sprint | Small patch or clear handoff after review | Quote after context |

## How Scope Is Confirmed

1. You open a public request with sanitized context.
2. I reply with a proposed scope, price, and acceptance criteria.
3. Private repo access, sensitive logs, and payment details are handled outside the public issue.
4. Work starts only after scope and payment path are agreed.
